# 점프!

설치 없이 실행하는 작은 점프게임입니다. 스페이스바, 위쪽 방향키 또는 화면 터치로 장애물을 넘으세요. 최고 점수는 브라우저에 저장됩니다.

## 로컬 실행

```sh
cd /workspace/SNB
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저로 접속하거나 `index.html`을 직접 열면 됩니다. 별도 패키지나 비밀키가 필요하지 않습니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다. `main`에 푸시하거나 Actions에서 Publish jump game을 실행하면 배포됩니다.

## 네모네모 곱셈 정원

## 딩동댕 작은 음악학교

## 은솔이의 우주 나눗셈 택배

`/division/`는 두 자리 이상 나눗셈을 동일 분배와 동일 크기 묶음의 두 관점으로 탐색하는 게임입니다. 기본은 24~99 ÷ 2~9(나머지 0)이며, 나머지 도전·100~999 ÷ 한 자리·두 자리 수(12~25)로 나누기도 제공합니다. 1/10/100씩 나눠 주거나 같은 수의 상자를 채우면서 몫과 나머지를 시각화합니다. 시범은 시간 제한 없이 중지·재시도할 수 있습니다. 정답은 나누는 수 × 몫 + 나머지 = 전체, 0 ≤ 나머지 < 나누는 수로 검증하며 정답마다 별 15~25개와 탐험 배지를 얻습니다. 별로 우주 기지 장식 6종을 구매하고, 별·완료 횟수·배지·기지·선택한 난이도는 localStorage에 저장됩니다. 실제 결제는 없습니다.

## 몽글몽글 아이스크림 가게

## 은솔 & 은별의 캐나다 클래스룸 패스파인더

`/canada/`는 한국에서 캐나다의 가상 메이플우드 학교로 전학 온 은솔·은별의 첫 주를 다루는 2D 도트 모험입니다. 교실·체육관·급식실·운동장을 직접 걷고 NPC와 대화합니다. 방향키/WASD로 이동하고 E/스페이스로 대화하며, 폰에서는 이동 화살표를 누르고 말 걸기 버튼을 사용합니다. 오늘의 퀘스트 버튼은 해당 NPC에게 바로 이동합니다. 책상·벽·나무·NPC 충돌이 적용되며 아래 출구로도 다음 장소에 이동합니다. 픽셀 캐릭터와 배경은 Canvas에서 직접 그리며 외부 이미지·라이브러리·음원이 없습니다.

첫 주는 7일/28개 활동과 우정 축제 엔딩으로 구성됩니다. 매일 암산 3문제(두 자리 덧셈·뺄셈·묶음 곱셈), Show & Tell 발표 카드 3장, 피구·달리기·릴레이를 표현하는 타이밍 3회, 한국어 뜻이 함께 나오는 영어 친구 대화를 진행합니다. 네 활동을 마치면 다음 날 이야기와 난이도가 열립니다. 암산은 시간 제한 없이 재도전할 수 있고 첫 시도에서 3초 안에 답하면 번개 보너스를 받습니다. 체육은 초록 게이지에 맞춰 화면 버튼/스페이스를 누릅니다. 탭을 벗어나면 이동 입력을 해제하고 체육 게이지를 멈춥니다.

은솔은 발표·체육 인싸력 +3과 넓은 타이밍 구간, 은별은 수학 인싸력 +3·적응력 +2 보너스가 있습니다. 인싸력·적응력·친구 3명의 친밀도·배지 6종·전학 일기를 수집합니다. 활동 보상은 하루 한 번, 친구 대화 보상은 친구별 하루 한 번 지급합니다. 중간에 대화를 닫으면 보상 없이 다시 도전할 수 있습니다. `canada-pathfinder-v1`에 자동 저장하며, 엔딩 후 친구 수첩과 일기를 보며 자유 탐험할 수 있습니다.

## 미로 탈출! — 괴물을 피해 달려!

`/maze/`는 괴물을 피해 초록 출구에 도착하는 30스테이지 도트 미로 게임입니다. 방향키/WASD 또는 큰 화살표 버튼을 꾹 눌러 이동합니다. 화면 스와이프로 한 칸 이동할 수도 있습니다. 별 3개는 선택 보너스이며 출구에 도착하면 별 개수와 관계없이 통과합니다. 각 스테이지는 하트 3개로 시작하고, 잡히면 하트 하나를 잃고 2초간 무적이 됩니다. 닿은 괴물은 멀리 떨어진 칸으로 옮겨져 계속 탈출할 수 있습니다. 하트가 없으면 같은 단계에서 다시 도전합니다.

미로는 연결된 통로를 무작위로 생성하고 막다른 길에 순환 통로를 추가합니다. 11×11에서 최대 21×21까지 커지며, 괴물은 1마리에서 5마리로 늘고 이동 간격은 850ms에서 415ms로 짧아집니다. 가까운 괴물은 벽을 통과하지 않고 최단 경로로 추격하며, 멀리 있으면 순찰합니다. 플레이어의 이동 간격은 125ms로 일정합니다. 단계마다 두 번, 5.5초 동안 출구까지 점선 경로를 보여주는 길 도움을 사용할 수 있습니다.

스페이스/멈춤 버튼으로 일시 정지합니다. 다른 탭이나 앱으로 넘어가도 자동으로 멈추며, 다시 계속하기를 눌러 재개합니다. 폰 세로·가로 화면에서는 미로와 이동 버튼이 함께 보이도록 배치했습니다. 별·하트·시간으로 단계 점수를 계산하지만 시간 초과는 없습니다. `maze-escape-v1`에 열린 단계·단계별 최고 점수와 별·소리 설정을 저장하며 새로고침하면 마지막 선택 또는 다음 열린 단계부터 새 미로를 시작합니다. 모든 그림은 Canvas로 직접 그리고 효과음은 Web Audio로 합성합니다. 외부 이미지·음원·라이브러리가 필요하지 않습니다.

## 올림포스 탐험대 — 그리스·로마 신화 퀴즈

`/mythology/`는 초등 중·고학년 수준을 목표로 한 신화 상식 퀴즈입니다. 올림포스의 상징·영웅의 모험·괴물과 수수께끼·약속과 변신·트로이와 귀향·로마 신화의 여섯 주제에 각 12개씩 총 72문제가 있습니다. 네 보기 중 하나를 터치하거나 숫자 키 1~4로 답합니다. 정답·오답 모두 해설을 보여주고, 답을 선택한 뒤 바꾸거나 중복 보상을 받을 수 없습니다. 아킬레우스의 뒤꿈치는 후대 전승임을 설명하고, 판도라의 그릇이나 페르세포네의 석류처럼 판본 차이가 있는 이야기는 조건과 해설을 함께 제공합니다.

신전마다 12문제 중 10문제를 출제하며 아직 맞히지 않은 문제를 우선합니다. 6개 이상 맞히면 다음 신전이 열립니다. 6~7개/8개/9~10개 정답으로 별 1/2/3개를 받습니다. 모든 신전을 통과하면 각 주제에서 두 문제씩 섞는 12문제 종합 도전이 열립니다. 일반 정답은 10점에 연속 정답 보너스가 붙고, 한 묶음에 두 번 사용할 수 있는 50:50 힌트로 맞히면 6점입니다. 힌트 정답도 통과 정답 수와 도감 수집에 포함합니다. 시간 제한과 실제 결제는 없습니다.

관련 문제를 맞히면 신·영웅·신비한 존재 24장의 도감이 열리고 그리스·로마 이름과 이야기를 읽을 수 있습니다. 최초 정답 경험치 10, 재정답 2, 오답 1로 지식 레벨을 올립니다. 틀린 문제는 오답 노트에 모아 해설을 읽고 최대 10개씩 다시 풀 수 있으며 재정답 시 노트에서 삭제합니다. `olympus-quiz-v1`에 신전 기록·경험치·도감의 근거인 정답 기록·오답·소리 설정과 풀이 중인 문제 순서/보기 순서/사용한 힌트/이미 선택한 답을 저장합니다. 새로고침 뒤 이어 풀기로 재개해도 보상이 중복되지 않습니다. 신화 내용은 `mythology/questions.js`, 게임 동작은 `mythology/game.js`에 있습니다. 그림과 효과음은 자체 SVG/이모지와 Web Audio를 사용하며 외부 서비스나 설치가 필요하지 않습니다.

## 쿵짝! 육상 3종

`/athletics/`는 삼단뛰기·창던지기·리듬 허들을 큰 버튼 하나 또는 스페이스바로 즐기는 2D 스포츠 게임입니다. 연습/기본/챔피언은 70/90/110 BPM이며 박자 판정과 파워·각도 게이지의 속도가 달라집니다. 3박 준비 후 경기를 시작하고, 멈춤 또는 Escape로 일시 정지합니다. 탭·앱을 벗어나면 자동으로 멈추며, 계속하기 뒤 두 박자 준비 후 같은 경기 시간에서 이어집니다. 폰 세로·가로 화면에서 경기장·게이지·조작 버튼을 함께 보여줍니다.

- 삼단뛰기: 초록 구간과 겹칠 때 홉·스텝·점프 세 번을 누릅니다. PERFECT/GOOD/OK/MISS 정확도로 각 도약 거리가 달라지고 세 거리를 합산합니다. 세 번 PERFECT는 18.00m입니다.
- 창던지기: 첫 입력으로 파워를 고정하고 다음 입력으로 각도를 고정합니다. 파워에 따라 초기 속도가 달라지고, 높이 2m·중력 9.81m/s²인 포물선으로 비행 시간과 착지 거리를 계산합니다. 공기 저항을 생략한 게임 모델이므로 45도 안팎이 유리합니다. 연속된 두 입력이 파워와 각도를 실수로 동시에 고정하지 않도록 짧은 중복 입력 방지를 적용합니다.
- 리듬 허들: 여섯 박자에 맞춰 실제 점프하며, 각 허들 통과 순간 발의 높이가 충분해야 성공합니다. 너무 이르거나 늦게 뛰면 걸립니다. 결과는 13.20초에 허들 걸림과 박자 실수를 가산한 게임 기록입니다. 난이도에 따라 달라지는 실제 애니메이션 재생 시간과 구분해 결과 화면에 설명합니다.

종목별 거리/시간 기준으로 금·은·동메달을 받으며 3종 대회에서는 세 종목을 연속으로 진행해 금 3점·은 2점·동 1점의 종합 결과를 냅니다. `rhythm-athletics-v1`에 난이도별 종목 최고 기록·메달, 종합 최고 점수, 난이도·유니폼 색·소리 설정을 저장합니다. 진행 중 경기는 새로고침 시 처음부터 시작합니다. Canvas로 직접 그린 경기장과 선수, Web Audio로 합성한 박자·멜로디·효과음을 사용하며 외부 이미지·음원·라이브러리는 없습니다.
