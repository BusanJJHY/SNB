# 점프!

설치 없이 실행하는 작은 점프게임입니다. 스페이스바, 위쪽 방향키 또는 화면 터치로 장애물을 넘으세요. 최고 점수는 브라우저에 저장됩니다.

## 로컬 실행

```sh
cd /workspace/SNB
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저로 접속하거나 `index.html`을 직접 열면 됩니다. 별도 패키지나 비밀키가 필요하지 않습니다.

## GitHub Pages

저장소 Settings → Pages → Build and deployment → Source에서 **GitHub Actions**를 선택합니다. `main`에 푸시하거나 Actions에서 Publish jump game을 실행하면 배포됩니다.

## 추가 게임

- `/racing/`: 좌우 이동 레이싱게임, 코인 상점과 폭탄 아이템
- `/rhythm/`: 4레인 리듬게임. D/F/J/K 또는 터치 패드로 플레이합니다.

리듬게임은 Web Audio로 자체 제작한 4곡을 연주하며 드럼/신스 모드와 FEVER 콤보를 제공합니다. 외부 음원이나 샘플, 별도 설치는 필요하지 않습니다. 음악은 시작 버튼을 누른 뒤 재생됩니다. 음악의 이용 조건은 `rhythm/README.md`를 확인하세요.

## 은별이의 반짝 덧셈 옷장

`/addition/`에서 한자리수 덧셈을 풀고 게임 코인으로 옷을 구매합니다. 기본은 합 9까지, 도전 모드는 합 18까지입니다. 정답마다 10코인, 오답은 다시 시도할 수 있으며 시간 제한은 없습니다. 옷 구매·착용과 코인은 localStorage로 같은 브라우저에 저장됩니다. 실제 결제나 계정은 사용하지 않습니다. 문제 읽어주기는 기기의 한국어 음성 지원에 따라 동작합니다.

## 보글보글 마라탕 가게

`/mala/`에서 손님 주문에 맞춰 재료를 선택하고 마라탕을 판매합니다. 청경채·당면·두부 3종으로 시작하며, 재료 8/12/16종을 모두 개방하면 자동으로 2/3/4레벨이 됩니다. 레벨업은 기존 재료·코인을 유지하며 축하 코인과 새 재료를 제공합니다. 벽지 4종·간판 3종·소품 5종으로 가게를 꾸미고 구매한 장식을 무료로 바꾸거나 배치할 수 있습니다. 배치된 소품마다 그릇당 팁 +1, 매 5번째 주문은 VIP, 3연속 정답은 추가 보너스, 도전 미션은 일회성 코인 선물을 제공합니다. 육수·광고는 판매가를 높이고 좌석 확장은 매 세 번째 주문에 단체 손님을 받게 합니다. 업그레이드는 다음 주문부터 적용됩니다. 시간 제한이나 실제 결제는 없으며 기존 `mala-shop-v1` 저장 데이터를 유지·확장합니다.

## 네모네모 곱셈 정원

`/multiply/`는 1m × 1m인 정사각형들을 가로·세로 배열로 보여 주는 곱셈/넓이 게임입니다. 칸마다 1m²이며, 길이는 m, 넓이는 m²로 구분합니다. 기본은 가로·세로 1~5m, 도전 모드는 1~9m입니다. 칸을 직접 누르거나 한 줄씩 칠해 넓이를 셀 수 있습니다. 정답마다 별 10개, 3연속 정답마다 추가 5개를 받아 정원 장식 6종을 구입합니다. 구입한 장식은 정원에 바로 배치되고, 별·완료 횟수·장식·난이도는 localStorage에 저장됩니다. 시간 제한이나 실제 결제는 없습니다.

## 공주님의 반짝 별나라

`/princess/`는 공주가 자동으로 별 마법을 발사하는 오리지널 슈팅게임입니다. 폰에서는 화면 드래그나 좌우 버튼, 컴퓨터에서는 좌우 방향키 또는 A/D로 이동합니다. 쉬운 모드는 하트 5개와 느린 구름 방울, 도전 모드는 하트 3개로 시작합니다. 보호막·하트 회복·8초간 두 줄 마법과 5단계 모험, 왕관 구름을 제공합니다. 다른 탭으로 전환하거나 창을 벗어나면 일시 정지하며 이어하기 버튼으로 재개합니다. 최고 점수는 localStorage에 저장됩니다. 소리는 버튼으로 켤 수 있으며 외부 음원·이미지·라이브러리를 사용하지 않습니다.

## 딩동댕 작은 음악학교

`/music/`에서 학교종(김메리 작곡)의 멜로디 24음을 연주합니다. 시간 제한 없는 따라 치기, PERFECT/GOOD/MISS와 콤보가 있는 리듬 도전, 자유 연주, 곡 듣기를 제공합니다. 피아노·리코더·실로폰·기타·오르골 소리는 Web Audio의 배음과 음량 곡선으로 합성하며 외부 녹음을 사용하지 않습니다. 빠르기는 72/96/120 BPM입니다. 폰은 건반 터치, 컴퓨터는 A/S/D/F/G/H/J/K로 연주합니다. 시작 버튼 또는 건반 입력으로 오디오를 활성화하며 탭을 벗어나면 멈춥니다. 최고 점수는 localStorage에 저장됩니다.

## 은솔이의 우주 나눗셈 택배

`/division/`는 두 자리 이상 나눗셈을 동일 분배와 동일 크기 묶음의 두 관점으로 탐색하는 게임입니다. 기본은 24~99 ÷ 2~9(나머지 0)이며, 나머지 도전·100~999 ÷ 한 자리·두 자리 수(12~25)로 나누기도 제공합니다. 1/10/100씩 나눠 주거나 같은 수의 상자를 채우면서 몫과 나머지를 시각화합니다. 시범은 시간 제한 없이 중지·재시도할 수 있습니다. 정답은 나누는 수 × 몫 + 나머지 = 전체, 0 ≤ 나머지 < 나누는 수로 검증하며 정답마다 별 15~25개와 탐험 배지를 얻습니다. 별로 우주 기지 장식 6종을 구매하고, 별·완료 횟수·배지·기지·선택한 난이도는 localStorage에 저장됩니다. 실제 결제는 없습니다.
