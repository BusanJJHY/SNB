# BEAT POP

오리지널 신스팝 「Neon Bounce」에 맞춰 D/F/J/K 또는 화면 패드를 누르는 4레인 리듬게임입니다. 120 BPM, 48초, 116개 노트. PERFECT는 ±75 ms, GOOD은 ±160 ms이며, 놓치면 콤보가 끊깁니다. 최고 점수는 브라우저에 저장합니다. 탭을 벗어나면 중단하고 다시 시작할 수 있습니다.

## 음악 이용 조건

「Neon Bounce」는 이 게임을 위해 새로 작성한 멜로디와 편곡입니다. 외부 녹음, 샘플 또는 기존 곡을 사용하지 않으며 Web Audio의 발진기와 생성한 잡음으로 연주합니다.

이 저장소의 「Neon Bounce」 음악 작품(멜로디와 편곡)은 **CC0 1.0 Universal**로 공개합니다. 복사·변형·재사용이 가능하며 출처 표시는 필수가 아닙니다. 이 선언은 음악 작품에 적용됩니다.

CC0 전문: https://creativecommons.org/publicdomain/zero/1.0/legalcode

## 실행

저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `/rhythm/`에 접속합니다. 시작 버튼을 눌러야 브라우저가 소리를 재생합니다. 이어폰이나 기기에 따라 소리 지연이 다를 수 있습니다.
