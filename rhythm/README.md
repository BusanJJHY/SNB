# BEAT POP

D/F/J/K 또는 화면 패드를 사용하는 4레인 리듬게임입니다.

## 곡과 모드

| 곡 | BPM | 길이 | 노트 |
| --- | --- | --- | --- |
| Neon Bounce | 120 | 48초 | 116 |
| Bubble Funk | 108 | 약 36초 | 80 |
| Star Rush | 144 | 40초 | 144 |
| Drum Parade | 128 | 약 38초 | 90 |

드럼 모드는 D=킥, F=스네어, J=하이햇, K=탐을 직접 연주합니다. 배경 드럼을 줄여 입력한 타격음을 들을 수 있습니다. 신스 모드는 전자음 타격과 전체 드럼 반주를 제공합니다. 노트가 없어도 누른 패드의 소리는 나며, 점수는 실제 노트 판정에만 지급합니다.

PERFECT ±75ms / GOOD ±160ms. 20콤보마다 5초 FEVER가 발동하고 그동안 점수는 2배입니다. MISS는 콤보와 FEVER를 끊습니다. 불꽃·파동·레인 빛·화면 충격·패드 반응·콤보 연출을 제공하며 강한 타격 효과를 끌 수 있습니다. 시스템의 동작 줄이기 설정도 존중합니다. 진동은 별도 선택이고 지원 기기에서만 동작합니다.

최고 점수는 곡과 모드별로 저장합니다. 기존 최고 점수는 Neon Bounce의 신스 모드에 유지합니다. 음량과 -200~200ms 판정 보정을 조절할 수 있습니다. 탭을 벗어나면 중단합니다.

## 음악 이용 조건

네 곡은 이 게임을 위해 새로 작성한 오리지널 멜로디와 편곡입니다. 외부 녹음, 샘플, 기존 곡을 사용하지 않습니다. Web Audio 발진기와 생성한 잡음으로 음악과 타격음을 합성합니다.

「Neon Bounce」, 「Bubble Funk」, 「Star Rush」, 「Drum Parade」의 음악 작품(멜로디와 편곡)은 **CC0 1.0 Universal**로 공개합니다. 복사·변형·재사용이 가능하며 출처 표시는 필수가 아닙니다. 이 선언은 음악 작품에 적용됩니다.

CC0 전문: https://creativecommons.org/publicdomain/zero/1.0/legalcode

## 실행

저장소 루트에서 `python3 -m http.server 8000`을 실행하고 `/rhythm/`에 접속합니다. 시작 버튼으로 브라우저 오디오를 활성화합니다.
